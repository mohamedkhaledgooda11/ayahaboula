# 🌸 صالون آية هبولة - دليل ملفات الباك إند (PHP + MySQL)

أهلاً بك! جميع ملفات الباك إند مكتوبة وموجودة فعلياً في المجلد الرئيسي للمشروع، ومجهزة لتعمل فوراً على أي استضافة (cPanel / Apache / Nginx / XAMPP):

---

## 📁 قائمة ملفات الباك إند وقاعدة البيانات:

| اسم الملف | المسار | الوصف |
| :--- | :--- | :--- |
| **`api.php`** | `/api.php` | معالج الـ API الرئيسي المكتوب بلغة PHP (إضافة حجز، جلب الحجوزات، تحديث الحالة، الإحصائيات، فحص الاتصال). |
| **`config.php`** | `/config.php` | إعدادات الاتصال بقاعدة بيانات MySQL عبر PDO، ضبط توقيت القاهرة الصارم، وترميز UTF-8. |
| **`schema.sql`** | `/schema.sql` | كود SQL الكامل لإنشاء قاعدة البيانات وجدول الحجوزات `orders` وجدول الإعدادات `settings` مع الفهارس. |
| **`database.sql`** | `/database.sql` | نسخة مطابقة لملف `schema.sql` لتسهيل الاستيراد في phpMyAdmin. |
| **`install.php`** | `/install.php` | **مثبت ويب تلقائي**: افتحه من المتصفح لإنشاء الجداول بضغطة زر واحدة بدون الحاجة لفتح phpMyAdmin! |
| **`test_db.php`** | `/test_db.php` | سكربت بسيط لاختبار الاتصال بقاعدة بيانات MySQL والتأكد من صحة بيانات `config.php`. |
| **`Code.gs`** | `/Code.gs` | كود Google Apps Script المستقل لربط شيت جوجل تلقائياً باللغة العربية. |
| **مجلد `backend/`** | `/backend/` | نسخة احتياطية من الملفات السابقة داخل مجلد مستقل في حال رغبت بتنظيم الملفات. |

---

## 🚀 خطوات تشغيل الباك إند على استضافة cPanel أو XAMPP:

### 1. إعداد بيانات الاتصال بـ MySQL:
افتح ملف **`config.php`** وعدل أسطر الاتصال:
```php
define('DB_HOST', '127.0.0.1');      // مضيف القاعدة (غالباً localhost)
define('DB_NAME', 'beauty_salon_aya'); // اسم قاعدة البيانات
define('DB_USER', 'root');           // اسم مستخدم القاعدة
define('DB_PASS', '');               // كلمة المرور
```

### 2. إنشاء الجداول في قاعدة البيانات (اختر إحدى الطريقتين):
* **الطريقة السريعة**: افتح في المتصفح الرابط:
  `http://اسم-موقعك.com/install.php`
  واضغط على زر **"ابدأ تثبيت وإنشاء الجداول الآن"**. سيقوم السكربت بإنشاء قاعدة البيانات وجدول `orders` وضبط الإعدادات تلقائياً!
* **الطريقة اليدوية**: ادخل على **phpMyAdmin**، أنشئ قاعدة بيانات باسم `beauty_salon_aya`، ثم اذهب إلى **Import (استيراد)** واختر ملف `schema.sql`.

### 3. اختبار عمل الـ API:
* افتح الرابط: `http://اسم-موقعك.com/api.php?action=ping`
  سيعطيك استجابة JSON فورية تؤكد عمل الخادم وقاعدة البيانات بتوقيت القاهرة.
* افتح الرابط: `http://اسم-موقعك.com/test_db.php`
  للتأكد من صحة اتصال PDO بعدد الطلبات الحالي.

---

## 🔄 كيف يتصل الفرونت إند بالباك إند؟
الواجهة الأمامية مبرمجة ومضبوطة مسبقاً لإرسال كافة الحجوزات إلى:
- **`POST /api.php`** مع المعامل `action: 'addOrder'`.
- يقوم `api.php` بحفظ الحجز فوراً في جدول `orders` في MySQL، ويقوم بالتوازي بإرسال نسخة لشيت جوجل إذا كان رابط الشيت مفعلاً (مزامنة مزدوجة تلقائية).
